# Streamlit dashboard

This directory contains the Streamlit application for Big Weather.

Read [`docs/contributor-instructions.md`](../docs/contributor-instructions.md)
and [`docs/streamlit-dashboard.md`](../docs/streamlit-dashboard.md) before
implementing or modifying the dashboard.

Expected structure:

```text
dashboard/
├── app.py
├── pages/
├── components/
├── services/
└── tests/
```

Run from the repository root with:

```bash
streamlit run dashboard/app.py
```

Document dashboard changes in `docs/dashboard-implementation.md`.
