The problem

The question is simple. Getting a fair answer is not.

We wanted to compare weather across 100 places and several years, and to see how it changes with height above sea level. That means millions of hourly records — and a download that stops halfway will quietly bend every average we calculate.

So the data engineering is the project, not a side task.
The source limits each request
We cannot ask for the whole history at once, so data has to arrive in small windows that we track.
Coverage is uneven
Some Sri Lankan places have six full years. Many regional places only start in April or May 2026.
The values are model estimates
Reanalysis data is not a weather station at each point, so our claims stay descriptive.

Rules we applied

Four rules that keep the numbers honest

Every hour exactly once
Each response must contain every expected hour, one time, with all requested fields — including empty ones.
A day needs all 24 hours
Incomplete days stay empty, so missing hours never look like a dry day.
Coverage is counted, not assumed
We judge coverage from saved records. A missing recent month is not the same as a paused download.
Every summary carries its count
Totals and means travel with the number of observations behind them, and 2026 is never called a full year.

How we analysed it

Four methods, one question each

Daily summaries
Average temperature and wind, total rain, only for complete days.
Q: what did a normal day look like here?
Correlation
Pearson and Spearman between height, latitude and average weather, over the same dates.
Q: does weather change with height?
Kruskal–Wallis test
11,322.14 for daily temperature and 4,650.22 for daily rain. The p-values are too small to print, not exactly zero.
Q: do the places really differ?
Spark cross-check
PySpark recomputed the same summaries independently and matched.
Q: are our rules applied consistently?
No forecast model was trained, so this deck reports no accuracy metrics.

Key findings

Four findings, with their evidence

Height matters more than latitude
r = −0.981 for height · r = −0.315 for latitude
Across this region, how high a place sits explains its temperature better than how far north it is.
The answer depends on the sample
Coastal sites r = +0.685, p = 0.133, height 3–10 m
Remove the height range and the relationship reverses, so any correlation must be reported with the sites behind it.
Rain and wind follow weaker patterns
Rain r = +0.337 regional, +0.285 (p = 0.126) in Sri Lanka · wind r = −0.506
Height is not in control of everything: exposure, geography and season still matter.
Sri Lanka's rain splits southwest to northeast
Galle 2,770.9 mm vs Jaffna 1,502.7 mm · 36 complete place-years
Yearly average temperature stays between 27.02 °C (2022) and 27.75 °C (2024), with no steady rise.

Why Snowflake and dbt
Managed storage with compute that can be suspended and scaled, plus one shared definition of each rule instead of the same logic copied into several API handlers. The cost is cloud dependence, spend to monitor and roles to administer.

Challenges & limitations

What got in the way, and what it cost us

Warehouse credits ran short
The ~$400 Snowflake trial was not enough for the MVP, so we simulated the warehouse locally with Parquet, PySpark and versioned release metadata.
The API limits each request
Full history for every place at once was impractical, so we took the newest windows first and left older data to be fetched on demand.
History is still uneven
Outside the matched dates, coverage varies by place, so the regional study covers only 119 days of one part-season.
The places were chosen
These are study sites, not a random sample, so country figures are not national averages.
Height is built into the source
Open-Meteo uses elevation when it downscales and picks grid cells, so part of the pattern reflects how the data is made.
Two requirements remain open
Warehouse integration and coverage-aware on-demand downloads are designed but not yet built.

Conclusions

What we built, found, and can defend

WHAT WE DID
Built a pipeline that keeps track of itself
1,230,960 checked hourly rows for 100 places, summarised under one rule and served to a map.
WHAT WE FOUND
Height tracks temperature; the sample tracks the answer
r = −0.981 regionally, −0.965 in Sri Lanka, +0.685 across six coastal sites, with weaker rain and wind patterns.
WHY IT MATTERS
Coverage discipline is what makes a comparison fair
The results support richer regional exploration — not a universal law about height, and not a claim about climate change.
Next steps

Five things we would do next

01
Deploy the warehouse
Snowflake roles and schemas, staged loading, dbt models and tests, then compare against the local reference.
02
Ship on-demand downloads
Coverage checks, cost estimates, workable alternatives and user-triggered fetches in the dashboard.
03
Fill in the history
Complete 2020 onwards for every place, so seasonal and yearly comparisons leave the 119-day window behind.
04
Use stronger statistics
Methods that allow for places and times being related, instead of exploratory p-values.
05
Measure and control serving
Report query, waiting and drawing time separately, with auto-suspend, monitoring and costs from measured loads.
